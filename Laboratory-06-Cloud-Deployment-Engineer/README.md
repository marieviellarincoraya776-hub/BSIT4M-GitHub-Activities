# Mission 6: The Cloud Deployment Engineer

## Mission Overview
Successfully deployed a multi-tier private cloud storage solution (Nextcloud and MariaDB) using Docker Compose and Infrastructure as Code (IaC) principles.

## Objectives
* Explain multi-tier application architectures.
* Create and configure `docker-compose.yml` files using CLI text editors.
* Deploy, verify, and tear down multi-container stacks.
* Document cloud engineering workflows in Markdown.

## Commands Executed
* `mkdir nextcloud-deployment && cd nextcloud-deployment`
* `nano docker-compose.yml`
* `docker-compose up -d`
* `docker-compose ps`
* `docker-compose down`

## Skills Learned
* Infrastructure as Code (IaC) with YAML.
* Multi-container orchestration and inter-container networking.
* Linux terminal text editing and container lifecycle management.
