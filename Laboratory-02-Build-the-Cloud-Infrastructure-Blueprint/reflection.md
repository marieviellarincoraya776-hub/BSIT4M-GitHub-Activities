# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think the compute resource is one of the most important cloud infrastructure components because it performs the processing required by applications and services. Without compute resources, applications would not be able to execute tasks, process data, or respond to users. In cloud computing, virtual machines and other compute services also allow organizations to scale their processing capacity based on their needs.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, flexible, and efficient operating system for servers and virtual machines. Many cloud environments use Linux because it supports virtualization, networking, containers, automation, and various cloud-based applications. Through the Linux terminal, administrators can also manage system resources and execute commands efficiently.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, configuration, resources, and procedures that will be used. It helps engineers understand the system before deployment and reduces the possibility of configuration errors. Good documentation also makes troubleshooting, maintenance, and future improvements easier.
