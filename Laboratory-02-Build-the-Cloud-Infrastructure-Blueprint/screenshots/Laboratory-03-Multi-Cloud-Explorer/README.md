# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory explores Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity focuses on comparing cloud services, analyzing business requirements, and recommending suitable cloud platforms.

## Mission Objectives

- Explore AWS, Microsoft Azure, and Google Cloud Platform.
- Identify core cloud services.
- Compare cloud platforms.
- Analyze business requirements.
- Recommend appropriate cloud solutions.
- Practice technical documentation using Markdown.
