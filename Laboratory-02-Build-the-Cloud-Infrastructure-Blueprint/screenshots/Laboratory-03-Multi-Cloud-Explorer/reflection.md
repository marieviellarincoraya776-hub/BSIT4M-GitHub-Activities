# Reflection

## 1. What did you learn about AWS, Azure, and Google Cloud?

I learned that AWS, Microsoft Azure, and Google Cloud Platform are major cloud computing platforms that provide similar core services but have different strengths. AWS offers a wide range of cloud services and has strong global infrastructure. Azure is highly suitable for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID. Google Cloud is particularly strong in data analytics, artificial intelligence, machine learning, and Kubernetes.

## 2. Which cloud platform would you personally choose and why?

If I were to choose a cloud platform, I would choose AWS because it provides a broad selection of services for different types of applications and organizations. Its services include computing, storage, databases, networking, security, and application deployment. I also learned that AWS can support both small projects and large enterprise applications, making it a flexible platform for future growth.

## 3. What surprised you about cloud computing?

What surprised me most was the number of services available from each cloud provider. Before this activity, I thought cloud computing mainly involved storing files online. I learned that cloud platforms can provide virtual machines, databases, networking, identity management, containers, artificial intelligence, monitoring, and many other technologies without requiring organizations to maintain all physical infrastructure themselves.

## 4. How can cloud computing help businesses?

Cloud computing can help businesses reduce the need for expensive physical infrastructure and provide flexible access to computing resources. Organizations can scale their resources depending on demand and can deploy applications in different regions. This can improve availability, support business growth, and allow companies to focus more on their applications and services instead of managing physical hardware.

## 5. How will this knowledge help you as an IT student?

This activity helped me understand how cloud platforms are used to solve real-world business requirements. As an IT student, learning about AWS, Azure, and Google Cloud gives me a better foundation for future subjects, projects, and possible IT careers. I also learned how to compare cloud services and choose a platform based on an organization's specific needs rather than simply choosing a provider based on popularity.
