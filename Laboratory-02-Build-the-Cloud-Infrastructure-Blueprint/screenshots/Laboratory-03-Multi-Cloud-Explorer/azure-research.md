# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, artificial intelligence, security, analytics, application development, and other cloud workloads. Azure allows organizations to build, deploy, manage, and scale applications using Microsoft's global cloud infrastructure.

## Global Infrastructure

Azure uses a global infrastructure consisting of geographies, regions, datacenters, and availability capabilities. Microsoft explains that an Azure geography contains one or more regions and is designed to address requirements such as data residency and compliance. Azure provides cloud regions across North America, South America, Europe, Asia Pacific, Australia, Africa, and other geographic areas.

## Cloud Management Console

The Azure portal is a web-based unified console for creating and managing Azure resources. Users can use the portal to create virtual machines, databases, storage resources, networks, and other services. The portal also provides dashboards, resource management tools, monitoring features, search, and access to Azure services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides virtualized computing resources that can run Windows or Linux operating systems. Organizations can use VMs to host applications, databases, development environments, and other workloads.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data. It can be used for documents, images, videos, backups, application data, and other files.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks within Azure. It provides networking capabilities for connecting virtual machines and other resources while controlling network traffic and connectivity.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage identities and control access to applications and cloud resources.

## Three Advantages

1. **Microsoft Integration** – Azure integrates closely with Microsoft's ecosystem, including Windows Server, Microsoft 365, and other Microsoft technologies.

2. **Enterprise Capabilities** – Azure provides services and management features designed to support enterprise applications, security, compliance, and hybrid environments.

3. **Global Infrastructure** – Azure provides cloud regions and datacenters in many geographic locations, allowing organizations to deploy services closer to users and meet data residency requirements.

## Typical Enterprise Use Cases

Azure can be used for enterprise application hosting, Windows Server migration, Microsoft 365 integration, hybrid cloud environments, database hosting, virtual desktop infrastructure, data analytics, artificial intelligence, and disaster recovery. Organizations already using Microsoft technologies can particularly benefit from Azure's integration with Microsoft's ecosystem.
